# Local v1.0.0 Milestone

Date recorded: 2026-05-25

This is a local project milestone record only. It is not a git tag, GitHub
release, crates.io publication, container publication, or public protocol
attestation.

## Scope Snapshot

- Directory Service profile routes are implemented for describe, query,
  ingest, PSI, and admin surfaces.
- Realm resource-kind migration and round-4 federation replay closures are
  recorded.
- CI hygiene includes fmt, check, test, clippy, typos, cargo-deny, cargo audit,
  tarpaulin threshold, and Trivy image scan wiring.
- Local release-hygiene scripts cover Trivy scan, SBOM generation, and optional
  cosign blob signing without pushing images or tags.
- Observability includes `/health`, `/readyz`, and loopback Prometheus metrics.
- Takedown receipts are recorded in `withdrawals.proof` with verifiable
  resource governance proof or service-signed operator receipt material.
- External security review readiness is documented as a package checklist, not
  as a completed vendor review.

## Remaining Non-Blocking Release Notes

- `tracing-opentelemetry` in-process OTLP export is deferred to a dependency
  refresh; operators can scrape Prometheus and collect tracing logs with an
  OTel Collector.
- Durable webhook retry and resource-side operator-takedown notification
  transport remain future work.
- Local validation may be blocked when the sibling `contrix-rust-sdk` checkout
  is on a prerelease version that does not satisfy teabay's manifest range.
